<a id="start-here"></a>
# 从这里开始

pokeldn 通过本地无线通信，与 Switch 或 Switch 2 上的宝可梦游戏进行交换。
通过 USB 连接的 ESP32 开发板负责无线通信，无需在游戏机上安装任何内容。

<a id="what-you-need"></a>
## 准备事项

- 带 USB 串口桥接芯片的经典 ESP32（ESP32-D0WD、WROOM-32E），或通过原生 USB 端口
  连接的 ESP32-S3、ESP32-C3、ESP32-C6。均使用 2.4 GHz，不支持 S2。
  Seeed Studio XIAO ESP32C3 需要连接随附天线，XIAO ESP32C6 使用内置天线。
- USB 数据线。仅支持充电的线缆不会显示串口。
- 从自己的 Switch 导出的 `prod.keys`，首次使用时选择一次即可。
- “游戏”页提供的七款游戏之一。

<a id="first-run"></a>
## 首次使用

1. 打开“开发板”页，连接开发板，点击“无线”旁的“安装”。应用识别芯片、写入固件后会自动
   检查开发板，收到响应后，页面顶部显示固件已更新。
2. 打开“游戏”页，选择游戏和工具。“主机”工具等待游戏机加入，“加入”工具搜索游戏机创建的组。
3. 在“用于交换的宝可梦”中搜索物种并点击“生成”。PKHeX 会生成适用于该游戏的合法宝可梦，
   初训家使用“设置”中填写的训练家。
4. “会话”面板的“开始前”会列出尚缺少的条件，并提供相应按钮。按“在游戏机上操作”中的步骤
   设置游戏机，然后点击“开始”。

带两个 USB 端口的 ESP32-S3、C3、C6 必须通过标有 USB 的原生端口与应用通信。
通过另一个 COM 或 UART 端口刷写固件虽然可以成功，但开发板不会响应应用，“开发板”页会提示
这种情况。连接多个开发板时，使用“使用此开发板”选择会话所用的设备。

物种下方的“更多选项”可设置性格、特性、性别、携带道具、精灵球、亲密度、个体值和努力值；
Let's Go 使用觉醒值，传说 阿尔宙斯使用奋斗等级。留空表示随机。列表仅提供该物种在当前游戏中
合法可用的选项，PKHeX 判定组合不合法时会拒绝生成并显示原因。

只有“设置”中的训练家与游戏机玩家一致，交换后的宝可梦才会保留亲密度；火红／叶绿每次交换
都会将亲密度设为 70。

物种下方的“添加交换”可在一次会话中按顺序交换最多六只宝可梦。完成一次交换后，主机会提供
下一只。所有交换工具都支持队列，每次交换收到的宝可梦分别保存为独立文件。

可以把文件拖入应用：将宝可梦文件或 Showdown 队伍文本（`.txt`）拖入交换卡片会填入该卡片，
拖到“添加交换”上则按文件加入队列。将礼物文件拖到礼物卡片会打开它；将 `.bin` 固件拖到
“开发板”页的固件卡片，在确认后即可安装。

收到的宝可梦保存在 `Documents/pokeldn/Received`，同时存入“银行”。银行的加号按钮或网格拖放
支持导入宝可梦文件及整个游戏存档；每只合法宝可梦只导入一次，原文件保持原样。跨世代传入时，
会按 HOME 的传入规则移除不允许携带的道具并忘记秘传招式。

<a id="free-up-storage"></a>
## 释放存储空间

“设置 → 存储”显示可以释放的空间。点击“清理本地文件”并确认，可删除会话记录、日志、临时
交换文件和未使用的已生成宝可梦。需要提交问题报告的记录应先保存。已接收的宝可梦、选中的
交换文件、密钥、固件和设置会保留。请先结束运行中的任务，再执行清理。

<a id="firered-and-leafgreen-language"></a>
## 火红／叶绿的语言

神秘礼物的“游戏机”卡片显示版本和自动语言检测状态。选择火红或叶绿后，在游戏的“朋友”列表
中选择 pokeldn。游戏机会报告卡带代码，应用据此选择对应语言的礼物脚本和 RAM 地址，再发送
代码。两个版本均支持英语、法语、德语、意大利语、西班牙语和日语。

当礼物因版本或语言而异时，保存原生 `.wc3` 文件需要选择卡带版本。`.pokegift` 可以保存全部
版本，并在游戏机连接时自动选择正确版本。“高级”中的训练家语言仅表示 pokeldn 在连接中报告的
训练家语言，不用于选择游戏机的语言。

<a id="basic-and-advanced"></a>
## 基本与高级

“基本”显示日常使用所需的字段，应用会自动采用各游戏已经验证的设置。“高级”列出当前会话
支持的全部选项及各自说明，其中填写的值会覆盖“基本”设置。除非指南或问题报告要求，否则无需修改。

不常用的设置位于“高级”顶部，包括自动结束会话的时限、无线信道和“每次运行生成新 PID”。
新 PID 可让已经收到过该宝可梦的存档再次接收；对必须保留固定 PID 的文件，例如部分活动宝可梦，
应关闭此选项。

<a id="your-own-pokemon-files"></a>
## 使用自己的宝可梦文件

“或使用宝可梦文件”可以打开从 PKHeX 导出的文件。应用会通过 PKHeX 检查，并在发送前显示其
合法性。不合法的宝可梦在对方游戏绘制时可能导致游戏崩溃。

<a id="mystery-gift"></a>
## 神秘礼物

神秘礼物工具提供四种主要方式：

- “使用预设”发送已经配置好的礼物。剑／盾的“官方活动”支持搜索真实活动卡片，包括宝可梦、
  道具、服装和对战点数。
- “自行构建”打开表单。火红／叶绿支持神奇卡片、正文、发放 NPC、礼物效果、神奇新闻和 ARM
  代码；剑／盾支持宝可梦、蛋、道具和对战点数。
- “打开文件”可发送他人分享的 `.pokegift`、火红／叶绿的 `.wc3` 或剑／盾的 `.wc8`。
- “自定义”将预设转入可以编辑的表单。

“发送前”显示游戏机将获得什么、何时生效及支持哪些卡带。问题以红色显示，解决前无法点击“开始”。

火红／叶绿的“游戏增强功能”可改变运行中的游戏，例如加速或增加跟随宝可梦。选择并发送后立即
生效，游戏重启后停止。要在重启后恢复，先启用“保存增强功能供以后使用”并发送增强功能，再发送
“由妈妈恢复增强功能”。每次重启后，与真新镇家中的妈妈对话即可恢复。跟随宝可梦会始终保存。
收到其他神奇卡片后，妈妈的礼物会被替换，需要重新发送恢复礼物。

“读取存档”会在会话日志中显示结果。训练家 ID（TID）是训练家卡片上的编号，里 ID（SID）通常
不会直接显示。同行队伍读取结果包含最后保存的队伍、性格、六项个体值（0 至 31）和努力值。
这些读取工具不改变存档和神奇卡片，训练家与队伍工具还会把读取数据保存到“已接收”目录。

“游戏机代码”在游戏接收礼物时于游戏内部执行。“离线检查”会先在模拟游戏机上运行，可能导致
菜单无响应的代码会被拒绝。原生代码可以改变游戏或存档，因此只应发送已经检查过来源和行为的代码。

“保存礼物文件”将当前礼物保存为可复用或分享的文件，不需要连接开发板。

火红／叶绿的“你的存档”可以把整个存档从 Switch 复制到电脑，或恢复到 Switch。
备份保留游戏机原存档，并按训练家命名显示在存档列表中。恢复时，游戏机会先逐部分检查新数据，
加载并保存；任何步骤失败都会保留原存档。恢复前请先备份。默认需要 PKHeX 判定整个同行队伍合法，
也可以手动开启“仍然恢复”。

存档保存在 `Documents/pokeldn/Saves`。可以重命名以便区分，导出 `.sav` 供模拟器或 PKHeX 使用，
通过加号或拖放导入 `.sav`。“查看与编辑”显示训练家、同行队伍和电脑盒子，可修改姓名、金钱和
代币，调整或移除队伍成员，为当前训练家生成宝可梦，并检查盒子中的合法性。“保留为新存档”会
生成独立副本，原存档保持原样。

<a id="when-a-run-fails"></a>
## 任务失败时

- 点击“停止”，退出游戏机的搜索画面后重新搜索。多数游戏会短暂保留失效的会话。
- 每次重试只改变一个设置，便于确定原因。
- 在“设置”中启用“记录每次会话”，通过“打开记录文件夹”查看记录，并将最新记录附在问题报告中。
